## Check first: is Items per Second the total over all copies?

**Yes. `target_output.items_per_second` is the total for all copies together.** The engine divides it by the copies to
get what one copy has to make, and the rate it reports back is the sum over the copies. Evidence:

- `clock-generator/src/crafting/target-production-rate.ts:18-22`: the config value becomes `total_production_rate`
  (`:27`), and `machine_production_rate` (`:25`) is that value `.divide(config.copies)`.
- `clock-generator/src/crafting/plan/plan-run.ts:1325-1333`: the machines' output capacity is multiplied by
  `config.target_output.copies` and compared with the *total* target. The error message names "Total output capacity".
- `clock-generator/src/crafting/alternatives.ts:461`: the rate the table shows is
  `achieved_output_items * 60 / clock_period * copies`, i.e. the all-copies total. (`achieved_output_items` is what
  one copy's clock-only run moved.)
- `clock-generator/src/crafting/rank.ts:47`: that total is compared with `config.target_output.items_per_second`
  (`rate_off_target`). The two sides are the same kind of number.
- `clock-generator/src/crafting/blueprint.ts:193-203`: the blueprint text already says it: "Target: 265 … per second
  over 5 copies (53 each)".
- `clock-generator/src/config/schema.ts:38-39`: the doc comment says only "Target production rate in items per second"
  and "Number of duplicate setups being modeled (multiplier for ratio calculations)". It never says total, which is
  what A16 and B13 found.

So the helper text says "total", and can also show the per-copy share (`items_per_second / copies`).

## Files

1. **`utils/numberText.ts` (new).** Pure, no React. The one place that decides how a number reads and the one place
   that holds this item's strings (named constants, so the 1.12 glossary pass edits one file).
   - `RATE_DECIMALS = 2`, `TICK_DECIMALS = 3`, `FIELD_DECIMALS = 3`.
   - `formatNumberText(value: number, options?: { maxDecimals?: number; locale?: Intl.LocalesArgument }): string`.
     Default `maxDecimals` is `RATE_DECIMALS`. Uses `Intl.NumberFormat(locale, { maximumFractionDigits: maxDecimals,
     minimumFractionDigits: 0, useGrouping: false })`, so it matches the number fields (which use the browser locale and
     no grouping). Rules:
     - rounds to `maxDecimals` and drops trailing zeros (`5.2`, `63`, `240`);
     - never shows a non-zero value as zero: when `0 < |value| < 0.5 * 10^-maxDecimals`, use
       `maximumSignificantDigits: 2` instead (`0.0004` stays `0.0004`; `1e-7` becomes `0.0000001`, not `1e-7`);
     - `-0` and `0` give `0`; a negative that rounds to zero is covered by the rule above;
     - non-finite values return `String(value)`.
   - `shownNumberText(args: { focused: boolean; value: number | null; inputValue: string; maxDecimals: number;
     locale?: Intl.LocalesArgument }): string`. Returns `inputValue` when `focused`, when `value` is `null` or not
     finite; otherwise `formatNumberText(value, { maxDecimals, locale })`. This is the whole display rule of the number
     field, kept pure so it is tested.
   - `maxRateLabel(rate: number): string`, giving `max 22.97/s`.
   - `itemsPerSecondHelper(itemsPerSecond: number, copies: number): string`. For `copies > 1` and both positive and
     finite: `Total for all ${copies} copies (${formatNumberText(itemsPerSecond / copies)}/s each)`. Otherwise
     `Total for the build`.
   - `COPIES_HELPER = "Identical copies you'll place. One clock fits each."`
   - `WAKE_UPS_HEADER = 'Wake-ups/min (1 copy)'`, `OUTPUT_PER_PERIOD_HEADER = 'Output per period (1 copy)'`,
     `rateHeader(copies: number): string` giving `Rate (items/s, all ${copies} copies)` for `copies > 1`, else
     `Rate (items/s)`.
   - `machineNodeCraftLine(ticksPerCraft: number, overloadMultiplier: number): string` giving
     `5.2t craft · insertion limit ×15` (ticks to 1 decimal, the multiplier through `formatNumberText`). The finding's
     "insertion limit" is right: the input limit is `ceil(ingredient amount × overload multiplier)`
     (`clock-generator/src/entities/machine/input/automated-insertion-limit.ts:10`).
