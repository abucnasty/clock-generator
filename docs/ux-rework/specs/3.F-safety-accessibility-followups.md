## Required outcomes

1. **Failed Copy** (C2E-1): a real rejected clipboard write produces visible and spoken failure, never false Copied
   success, and a usable keyboard/manual-copy route to the selectable blueprint string. Preserve stale confirmation,
   below-target warning and3.3's provisional-copy pinning. Inspect current P3 hook/App contracts before adding a
   callback. Use existing messages/live-region machinery, not a second global error mechanism.
2. **Fuel equivalence** (C2E-2/originalC2): expose each displayed event's inserter, start/end and quantity through a
   keyboard/touch/text equivalent, such as a labelled events-table disclosure; summarize the actual fuel trace,
   minimum and empty intervals where the existing data supports them. Do not invent measurements or engine data.
   Avoid hundreds of unnecessary Tab stops when a complete accessible table supplies equivalent information. Fuel
   remains player-facing; old developer-timeline scope exclusions do not waive this data.
3. **Partial Paste** (A-P2-02/B2/C2E-3/B19/N35): show current→incoming counts and explicit consequences for references
   crossing replaced/retained entity categories, in both directions where relevant. Require deliberate acceptance
   of a potentially mixed build without silently rebinding endpoints or forcing category choices. Counts describe
   what the actual destination will lose/retain. Preserve target selection, whole-Paste Undo, metadata/fractions and
   library behavior. Append is excluded; no engine graph validator or new sidecar format.
4. **Output-swing scope** (C2E-7): inspect the current engine quantity first, then correct Overrides/check-plan copy
   to distinguish its aggregate output-machine count from a per-inserter count and explain the split accurately.
   No arithmetic or planner change. Cover a real multiple-output-inserter case.
5. **Advanced help** (C2E-8/N23): reuse established click/tap HelpButtons for long explanations and verify actual
   accessible descriptions on their fields/switches. Preserve values/labels, focus restoration and existing shortcuts.
6. **Stale plan** (A originalC21/B20/C2E-11/N32): retain readable read-only information with its out-of-date warning;
   actions must remain correctly inert for keyboard and pointer. Replace whole-plan opacity as appropriate after
   measuring the actual state. The original0.45 observation is not itself a new measured AA failure.
7. **320px reflow audit**: capture actual ordinary UI, main actions/errors/dialogs and representative forms/results
   at320 CSSpx. Distinguish legitimate two-dimensional table/diagram exceptions from ordinary UI overflow. Fix
   demonstrated ordinary-UI accessibility gaps without designing the deferred phone comparison/Compact layouts.
   If an actual requirement still conflicts with an owner decision, bring concrete evidence/options to the owner;
   do not silently waive AA or claim unrestricted conformance from sampled automated checks.
