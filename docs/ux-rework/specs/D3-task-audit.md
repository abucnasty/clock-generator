## Minimal measurement and scorecard

Use temporary capture instrumentation beside existing `capture/lib.mjs`/provider helpers; no permanent framework, regression suite or new dependency. Root owns commands/servers/native captures and one serial clipboard process lane. Do not run clipboard captures concurrently with other widths/processes.

For each task emit one compact event trace: task start/end anchors(time, URL/view, focus, selected build/candidate, visible label/state, scroll offsets), native input events, settled outcome and linked screenshots. Count deliberate control activations(pointer clicks or keyboard activation), committed field edits and file commits once each; separately count navigation keys(Tab/Shift-Tab/arrows), edit keystrokes and wheel gestures. Select-All/type/Tab is one committed edit plus separately recorded keys, not one action per character. A dialog opened/confirmed is counted as its actual activations. Record retries/detours rather than erase them. UI-auto navigation is an outcome, not a phantom click.

During measured tasks find offscreen controls with native mouse-wheel input of±450 CSS-px per gesture, settling until scrolling stops; reverse when needed and retain overshoot. Keep the same gesture policy in repeats. Do not use `scrollTo`, `scrollIntoViewIfNeeded`, forced clicks or offscreen locator auto-scroll. Click only after visible native reachability. Observe actual document **and nested** scroll offsets: sum absolute user-caused vertical deltas per scroller; record maximum displacement/range, wheel count and horizontal table scrolling separately. Associate genuine keyboard-caused scrolling with its key; log app-restored/automatic scroll separately. Avoid double-counting bubbling wheel events or simultaneous ancestor reports. Wheel input delta is not actual distance. If the harness unexpectedly scrolls, label/exclude it, retain evidence and replay that task from its recorded UI start if needed.

Keep harness prep/framing and screenshots outside measured intervals. Helpers such as importFile/direct setInputFiles, goConfigure/goResults/generate/reset scroll and locator screenshot/contrast/focus probes cannot silently replace measured routes. Record full page/scroll-container extent at anchors as **layout extent**, separately from actually traversed distance; it is not scroll fatigue. Capture task-end viewport without reframing; any later full-page slices/framing have their own excluded log. Reuse source/state-matched ordinary captures where sufficient.

Record engine generation wait separately from task interactions. Total wall time, agent reading/reasoning/automation overhead and harness waiting are labelled descriptive, never human completion time or engine performance claims.
