# Retired custom capture and audit harness

The owner requested removal of the custom full-AA capture/audit harness before the Phase4 PR is ready for review. Phase4's final cleanup removes all55 tracked scripts (34,879 lines), shared capture helpers/self-tests and five harness-only JSON fixtures.

The Markdown files here are historical acceptance records, not a runnable framework or instructions for future work. Their script paths refer to source available in Git history before this cleanup. Original engine/sample builds are unchanged.

Use the [focused keyboard-and-colour profile](../specs/keyboard-colour-profile.md) and ordinary functional checks. Targeted actual UI checks and fresh review screenshots use existing browser capabilities; do not rebuild this harness or require custom identity, selector, exhaustive capture or audit matrices.

[Phase4 evidence and reviews](../review/phase4/EVIDENCE.md) preserve the completed checks. Ordinary unit/regression/contrast tests, runtime accessibility features and CI stay in place.
