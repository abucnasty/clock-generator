# D3 Task-based usability audit — approved Phase 4 scope

Owner approval, 2026-10-16: A / A / A. Phase 4 targets `feat/ux-rework`. This bounded exercise is integrated with Phase 4, with a baseline before D1 and a repeat after Phase 4. Detailed task/build selection remains to be finalized before execution.

## Approved exercise

Use two representative builds and these three tasks for each:

1. Import a build, inspect/change one thing and generate.
2. Compare clocks, choose one and copy its blueprint.
3. Reopen a saved build and locate the applicable installation/wiring guidance.

Select existing representative small and larger/complex build inputs where available; pin the input and source identity. Keep baseline and follow-up task goals, viewport, starting state and build data comparable. Account explicitly for intended UI changes rather than comparing unrelated states or samples.

Record scroll distance, interactions, task completion and observed interpretation problems. Agent walkthrough observations must identify their basis and must not be presented as human-user study results. Owner participation is optional; this approval does not add another required owner walkthrough.

## Deliverable and boundaries

- One short before/after scorecard linked to sufficient reproducible evidence, with baseline captured before D1 and the same tasks repeated after Phase 4.
- Use the exercise to inform the approved density work and assess the resulting workflow. Findings outside approved scope return for owner decision; no automatic additions to Phase 4.
- This is not an extra broad exploratory audit, a new automated regression suite or a replacement for independent reviews. Reuse relevant normal evidence where inputs and measured states match.
- Existing checks, independent code/UX review and all three phase-end reviewers remain required. Already-passed in-game installation checks are not repeated by this web-task exercise.
- Finalize exact builds, task instructions, completion criteria and measurement method in the item spec. Avoid arbitrary targets or claims that a smaller scroll count alone proves better usability.
